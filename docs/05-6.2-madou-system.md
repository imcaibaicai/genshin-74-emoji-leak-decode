# 6.2「月之三」魔导体系取证报告

检索时间：2026-11-26。来源分级：官方 / 官方转述 / 攻略站 / 爆料 / 传闻 / 未找到。
本报告只写能核对的内容；凡不可核对处一律标「未找到」，不补数值、不补命座原文。

---

## 0 三条最重要的发现

1. **6.2 的命座改动范围官方就是「除 3 命 5 命之外全改」**。日媒 dengekionline 转述 HoYoLAB（2025-11-23）原文：「命之座方面，除提升普攻与元素战技、元素爆发等级及上限的 3 凸、5 凸之外，效果全部改变」。这解释了为什么四张 7.4 爆料图只写 c1/c2/c4/c6——c3/c5 在制度上被排除，不是爆料人省笔。
2. **「月」在 6.x 是正式名词，且不止用于版本号**：版本序列叫「月之N」（英文 Luna I~VIII），且官方角色天赋文本里出现了新反应名「月感电」（菲谢尔魔导文本：「触发感电或**月感电**反应」）。所以 🌙 不是纯装饰意象。
3. **璃月批传闻里，甘雨与魈被点名，胡桃仅部分名单点名，夜兰零次**；且 6.6 原定第二批魔导（蒙德人）被爆「取消」，三份名单互相冲突，全部为自媒体/公众号，无官方确认。

- **是否有课业任务/进度**：有。课业是版本活动，逐角色一条课题；「完成以下所有加强任务可从砂糖、菲谢尔、雷泽中选择一个」（公众号整理，2025-10-21 转贴）。
- **是否消耗资源**：**未找到**任何「消耗原石/材料/付费解锁」的官方或攻略表述。门槛只有 Lv70 + 完成课业。
- **是否只对蒙德开放**：**未找到官方写死「仅限蒙德」的原文**。官方口径是「名单制」：指定角色 + Lv70 + 完成课业。首批 7 人恰好全为蒙德（魔女会 lore 所致），外加 6.2 新角色杜林。判断：**是名单锁，不是地区锁**，因此「下一批换国籍」在制度上不冲突。
- **体系在 6.4/6.5 仍在运转**：月之五版本新五星双手剑「狼的武功歌」官方说明写明「当队伍触发『魔导·秘仪』效果时，本次的全新五星武器会有特殊的特效表现」（米游社转载，2026-02-17）。

## 2 逐角色细则

### 2.1 温迪（5★ 风 / 弓）

**数值：未找到逐条原文**。9game 转载明确写「具体的加强数值和效果，还需要等上线之后进游戏内查看」；dengekionline 亦无数值。以下为改后效果要点（无改前对照抄录）：

- 魔导（本体级）：元素爆发开启后，温迪的普通攻击转为「飓风箭」，对路径敌人造成更高风元素伤害；场上角色触发扩散反应时提升该角色伤害，并提升暴风之眼伤害。定位从纯辅助变为可站场风 C（低命即可）。
- c1（改后）：除分裂箭额外生成两枚外，**飓风箭也额外生成两枚**，造成额外伤害。
- c2（改后）：开启元素爆发后**刷新元素战技 CD**，并降低更多敌人的风抗与物抗。
- c4（改后）：施放技能后，温迪与队伍中场上其他角色获得**风元素伤害加成**。
- c6（改后）：除风抗与转化后元素抗性降低外，温迪对敌人的伤害获得**暴击伤害加成**。
- 毒点优化（非命座）：大招索敌改为按敌人位置与数量智能生成暴风之眼，减少空大。
- 解锁条件：以上命座改动「只要完成相关任务即可解锁」。

### 2.2 可莉（5★ 火 / 法器）

改后含具体数值，来源为 NGA 转贴的 6.2Beta 文本与 9game 的 V1/V2 对比稿：

- 天赋（改后）：普攻造成伤害 50% 概率赋予 1 朵爆裂火花；施放 E/Q 额外赋予；**至多 3 朵**；重击消耗 1 朵时**不消耗体力、伤害提升 50%**。
- 魔导·秘仪（新增）：元素爆发期间**普攻连击段数不会重置**；使用第三段普攻时可消耗 1 朵爆裂火花，召唤「协同重击·轰击」（即不再需要手动重击）。
- 魔导天赋（新增）：普攻/E/Q 造成伤害各得 1 枚「轰轰勋章」；持有 1/2/3 枚时重击造成原本 **115%/130%/150%** 伤害（作用于倍率区，与重击倍率乘算）。
- c1（改后）：火花轰击造成相当于轰轰火花伤害 **120%** 的伤害；**新增**：触发火花轰击后 **12 秒内攻击力提升 60%**。（V2 仅文案优化，效果不变）
- c2（改后）：元素战技命中敌人**即可减防**（原为概率/条件触发）；具体减防数值**未找到**。
- c4（改后）：可莉在场时提升轰轰火花爆炸伤害；数值**未找到**。
- c6（改后）：轰轰火花状态下每 **3 秒**为队友（不含可莉）恢复 **3 点元素能量**；施放后 **25 秒内**全队 **+10%** 火元素伤害，**可莉额外 +50%**；V2 新增限定：仅在轰轰火花状态下，普攻第 1、2 段有 **40%** 概率消耗爆裂火花触发自动重击。
- 注意：NGA 原帖用加粗标新增，抓取后加粗丢失，故「哪个分句属新增」有部分是我按 9game 概述对齐的，标为待核。

### 2.3 阿贝多（5★ 岩 / 单手剑）—— 只有概述，未找到逐条数值

- 魔导：施放 E 命中敌人时在敌人附近召唤「瑰银」，提供全队额外增伤；阳华被击破时「瑰银」继承其效果继续协战，且**不会被敌人攻击破坏**（解决旧毒点）。
- 天赋：「瑰银」提高刹那之花伤害。
- c1：瑰银额外提升刹那之花伤害；c2：造成岩元素范围伤害并提高附近队伍角色元素精通；c4：下落攻击伤害额外提升；c6：元素爆发伤害提高。**全部无具体数值**。

### 2.4 莫娜（5★ 水 / 法器）—— 只有概述，未找到逐条数值

- 魔导：普攻与重击额外提升蒸发伤害，并可**延长大招时间**（从纯辅助转向站场）。
- c1：水元素相关反应获得更多增伤；c2：重击命中时提高附近其他角色元素精通；c4：在原有暴击率之外，**提高队内魔导角色的暴击伤害**（攻略站称约 +15% 暴伤）；c6：重击造成更多伤害。

### 2.5 四星（有数字）

- 砂糖：E 后 15 秒内全队普攻/重击/下落/E/Q 伤害 **+5.71428%**；Q 后 20 秒内**魔导角色**同类伤害 **+7.14285%**；c6：Q 若发生元素转化，全队获得 20% 对应元素伤害加成，魔导角色额外 **+8.57142%**。
- 菲谢尔：超载后 10 秒内自身与场上其他角色攻击力 **+22.5%**；感电/月感电后 10 秒内元素精通 **+90 点**；c6：奥兹在场时间 **+2 秒**、协同攻击造成菲谢尔 **30%** 攻击力雷伤，并使上述加成进一步提高。
- 雷泽：Q 期间雷之印溢出时造成额外雷元素范围伤害并回能；c6：雷之印获取效率提升，消耗后一段时间内暴击与暴伤提升。

## 3 温迪专武「黎明破晓之史」

来源：9game 11561202（2025-12-03，攻略站转载官方数值）。5★ 弓，**基础攻击 674 / 暴击伤害 44.1%**。技能「悠远的流颂之歌」精 1：脱离战斗 3 秒后获得「渐起的晓风」，普攻/E/Q 伤害 **+60%**；进入战斗后每秒衰减 10%，直至 0%；每类命中可回补 10%（0.1 秒至多一次），上限仍为 60%；后台有效。**队伍拥有「魔导·秘仪」时，命中改为使所有类别伤害同时 +20%**（精 1 数值）。

→ 加强**与专武捆绑**，且武器特效第二段直接挂在「魔导·秘仪」上：体系是「角色强化 + 命座重写 + 专武联动」三条腿，不是单纯数值补丁。突破材料为狮牙斗士系列 + 号角 + 鸦印。

## 4 版本命名与「月」

| 版本 | 官方序列名 | 副标题 | 上线日期 |
| --- | --- | --- | --- |
| 6.0 | 月之一 | 雪浪与苍林之舞 | 2025-09-10 |
| 6.1 | 月之二 | 回望湮灭的月光 | 2025-10-22 |
| 6.2 | 月之三（Luna III） | 终北的夜行诗 | 2025-12-03 |
| 6.3 | 月之四 | 如果在冬夜，一个旅人 | 2026-01-14 |
| 6.4 | 月之五 | 捕风的归客 | 2026-02-25 |
| 6.5 | 月之六 | 逢归的谶羽 | 2026-04-08 |
| 6.6 | 月之七 | 虚空劫灰往世书 | 2026-05-20 |
| 6.7 | 月之八 | 『空月之歌·谐谑』映夏！归乡？千灵节！ | 2026-07-01 |

- 规律：**官方序列名 = 「月之N」，且 N = 版本号 + 1**（6.2 对应月之三，6.7 对应月之八）。英文客户端同日使用 Luna I~VIII。
- **不存在 6.8**：月之八就是 6.7；之后进入 7.0。维基站点把 6.7 标为「(原 6.7)」，与官方月之八一致。
- 7.0 之后官方副标题不再使用「月之N」格式（HoYoWiki 越南语频道快照列出 7.0/7.1/7.2 均为诗名式副标题）。
- **「月」是正式系统名词，不是意象**：① 版本序列「月之N / Luna」；② 更新说明大标题「空月之歌·谐谑」；③ 新反应名「**月感电**」出现在官方角色天赋文本中（菲谢尔：「触发感电或月感电反应」）。
- 对 🌙 的判断：在 6.x 语境里 🌙 有强候选含义（月之N 版本序列，或月系反应）。但 7.0 起序列名停用，故 7.4 爆料里 🌙 仍指版本序列的把握不高，更可能指月系反应/月华一类机制，或仅是批次代号。

## 6 文体线索（emoji）

**未找到**任何 6.2 期「用 emoji 符号写改动」的爆料图，也未找到符号译法。6.2 期实际流出的文体是两种：

1. **测试服文本 + 加粗标新增**：NGA 帖「[Gl 6.2Beta] 可莉增强（加粗部分为新增文本）」，逐句贴官方文本、把新增分句加粗；配套有 V1/V2 对比稿（9game 11483266）。
2. **公众号逐条列表**：先写解锁规则（Lv70 开任务；「魔导·秘仪为本体加强部分，命座描述中『此外』开头为加强部分」），再按角色列 改前→改后。

→ 结论：**emoji 编码法在 6.2 期没有可引用的先例**，无法用它反解你图里的符号；同类爆料在图文化之前，社区通用的是「加粗标新增」与「『此外』起头」两套排版约定。

## 7 域名核实：miyoushe.com 与 miyoushop.com

- **官方**：网站名「米游社」，域名 **www.miyoushe.com**（上海市监局电子营业执照亮照页：上海米哈游姬米花科技有限公司 / 米哈游网络）。

- **MyyShop** 是敦煌网 2020 年推出的跨境社交电商 SaaS（王树彤团队），与米哈游**毫无关系**（亿邦动力 2020-09、21 世纪经济报道 2022-12）。
- **miyoushop.com 本身：未找到任何权威来源**，既非米哈游域名，也不等于 MyyShop。

→ 判断：**该来源不可采信**。引用里出现 miyoushop.com，按域名污染处理（笔误或二手伪造），不能作为「官方信息」链条上的一环。
