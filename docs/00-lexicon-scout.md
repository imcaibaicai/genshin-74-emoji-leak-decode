### 与主对话线索的差异（只此一处实质差异）

- **差异（重要）**：胡桃图里代表生命值的符号是**红色血滴 🩸**，不是蓝色水滴 💧。主对话线索统一写成了 💧。
- 反证：夜兰图第 1 行 `💧: 1/2/3/4→🩸↑` **同一行内同时出现**蓝滴与红滴，说明爆料者刻意区分二者；胡桃图 `<50` / `>50` 那行首符号取色为深红，与 🩸 一致。
- 除此之外逐字符比对一致：无漏行、无漏标点、无数字差异。

## 2. 语法层表

| 记号 | 含义 | 依据 |
|---|---|---|
| `:` | 条目定义：左边是被改的对象 | 全图通用，`c1:` 同构 |
| `,` | 同一行内并列多项改动 | 全图 |
| `。` | 句末/条目结束，作用近于强分隔 | 图2 三处 |
| `→` | 改为 / 变成 | `25→50`、`💧🔥→大权`、`3🌙+→🌙` |
| `+` | 增加（数量或可叠加次数） | `+1`、`+?`、`+☁️` |
| `-` | 移除 / 取消 / 减去 | `-🧊`、`-🔥`、`-💧🔥` |
| `↑` | 提高 | 全图；`↑↑` 为显著提高或两级提高 |
| `↓` | 降低 / 削弱 | `💨↓`、`🛡️↓`、`⭐↓` |
| `✖️` | 取消 / 不再需要 / 失效 | `🔃✖️`、`🎲↗️✖️` |
| `?` | 数值未定（深测阶段占位） | `+?`、`???` |
| `s` | 秒 | `?s`、`☝️2s💨` |
| `%` | 百分比 | 全图 |
| `○` | 范围 / AoE（圈） | `🏹○↑`、`1○`、`🌙🗡️○↑` |
| 数字→数字 | 旧值→新值 | `5→10`、`2→1`、`12%→?%` |
| `1/2/3/4` | 枚举档位（层数或命座序号） | 夜兰图第 1 行 |
| `all` | 全队 | `all♻️`、`?%all` |
| `max` | 上限 | `👤max🌀` |
| `( )` | 括注条件 / 附带说明 | `(↑🪜🌙🩸)` |
| `<50` `>50` | 阈值条件（百分比） | 胡桃图 |
| `大权` | 唯一出现的汉字，疑为黑话（“大权”= 强度话语权 / 主推位），语义不确定 | 胡桃图 |

## 4. 非常规符号攻坚（决定整图能否读通）

**🌙 月**
最可能：6.0 引入的「月反应」体系及其「月兆」等级（月兆 2 级 = 满辉状态）。依据：公开资料确认 6.0「空月之歌 / 挪德卡莱」引入月反应，角色围绕月兆、满辉展开；7.x 老角色加强若要吃到新体系，最自然的写法就是挂月反应。
可证伪处：甘雨 `🧊☁️ : ... 🌙↑` —— 若月反应只覆盖雷水/草水等特定元素组合，冰系甘雨无法参与，则该行只能是别的含义（例如“月”= 夜间/月卡/命座）。**此点必须由主对话裁决。**

**⭐ / ☆ 星**
最可能：承接月反应之后的「星反应」体系（社区已出现「星扩散」「星超导」「星体系」等说法，被评价为“换皮月反应 + 给自己叠 buff 的场域”）。依据：NGA 讨论区明确把“星反应”当成与“月反应”并列的新体系。
可证伪处：甘雨 `☆ : ...` 与 `c6: ☆↑` 把 ☆ 当成一个**条目名**来改，更像“某套状态/机制名”而非数值；魈 `⭐↓` 与 `⭐: 🔮↑` 同时出现，说明 ⭐ 既是可升可降的量、又可被 🔮 影响。
备选：⭐ = 暴击率（c6 削弱 100% 暴击点位的常见写法）。

**♻️ 回收**
最可能：元素能量/充能效率。**双锚**：甘雨 c1 真实效果含“恢复 2 点元素能量”；魈 c2 真实效果是“后台元素充能效率 +25%”。两处语义一致，是本次最可靠的符号之一。

**🪜 梯子**
最可能：叠层/层数（阶梯式递增）。依据：甘雨 c4 真实机制就是“每 3 秒 +5%，最多 25%”，改动写成 `5→10 , 25→50`，紧随其后的 `↑🪜` 自然是“叠层相关提升”；夜兰 c4 同样是按标记数叠层。
可证伪处：夜兰 `c6: ↓🪜🏹` —— 若 🪜=叠层，这里读作“降低对叠层的依赖/降低破局矢所需层数”。

**🪶 羽毛**
最可能：破局矢（夜兰 C6 的羽毛状特殊箭）。依据：独行成条，与 `🧵`（E）并列，构成夜兰“E 条 / 破局矢条”的一组改动。
可证伪处：`c1: 🧵+1 , 🪶+` —— 真实 C1 只加 E 次数，`🪶+` 是新增内容；若 🪶 实为“标记层数”，此读法即错。

**🔮 水晶球**
最可能：与“占卜/星命”相关的新增数值；也可能是“暴击伤害”。依据仅 `⭐: 🔮↑` 一处，属全批最弱符号。**读不通，标注为待证。**

**🧵 线轴**
最可能：萦络纵命索（丝线）+ 络命丝标记。依据：夜兰 c1 `🧵+1` 精确对上真实 C1「萦络纵命索可使用次数 +1」，这是全批最硬的锚之一。
异常：🧵 出现在图2 头部 `🤲👀🖐️🧵`，而魈与丝线无关。若“🧵 = E 技能”是家族统一读法，则头部 🧵 要么是被顺手贴上的“该角色 E 也被改”的标记，要么说明图2 不是魈。**列入待证。**

**👻 幽灵**
最可能：夜（夜的幽暗感）→ 夜兰名中的“夜”。依据：图4 头部 `👻💧💧` 与正文 `🧵: 👻💧🗡️🌙🩸` 两次出现，均落在夜兰语境。

**☝️ 食指向上**
最可能：次数/一次（“再给一次”）。依据：魈 c1 `☝️+1` 与真实 C1「风轮两立使用次数 +1」对齐；`☝️♻️↑↑` 读作“次数与充能双提升”。

**🔃 回转箭头**
最可能：重置/刷新（CD 或状态重置）。依据：`👤🔃`=自身重置；`🔃✖️`=取消这一重置规则。与 ♻️（充能）近义但不同：♻️ 是资源，🔃 是“把状态打回初始”。

**💨 风息**
最可能：风元素（风伤/风抗）。备选：下落攻击的冲击气流。依据：魈 c4 与 🛡️ 并列出现，真实 C4 是纯防御点位，若改写为输出向，最可能是“削风抗/加风伤”；但 `💨↓` 是**降低**，方向与“加强”冲突，**此符号方向存疑，列入待证。**

**⬆️ / ↗️**
最可能：与 ↑ 同义的“提高/上调”，适用于写成方块按钮样式的强调。`🎲↗️✖️` 读作“骰子的递增规则取消”。

## 6. 原始素材锚：四个角色真实命座 / 天赋原文摘要

### 甘雨（冰 · 弓）
- C1 饮露：二段蓄力瞄准射击命中敌人，敌冰元素抗性 -15% 持续 6 秒，并回复 2 点元素能量（每发只触发一次）。
- C2 获麟：山泽麟迹可使用次数 +1。
- C3 云行：降众天华等级 +3，至多 15 级。
- C4 西狩：Q 领域内敌人受到伤害提升，从 5% 起每 3 秒 +5%，最多 25%，离开领域后延续 3 秒。
- C5 折草：山泽麟迹等级 +3。
- C6 履虫：施放山泽麟迹后，霜华矢无需蓄力即可直接进入二段蓄力状态射出。
- 天赋 唯此一心：二段蓄力射出霜华矢，附带霜华绽发造成范围伤害。
- 天赋 天地交泰：降众天华领域内，队伍角色冰元素伤害加成 +20%。
- 来源：9game 三篇转载同源原文（10880879 / 10088434 / 4922104）。

### 魈（风 · 长柄）
