# 03 「emoji + ? + 箭头写改动」爆料文体的历史先例与现成译稿

取证时间：2026-11-26（Asia/Shanghai）。取证方式：公开检索 + 公开页面抓取，未登录任何受限站点。
证据分级：原始爆料 / 搬运 / 社区翻译 / 官方。

## 一、结论速览

1. **同款文体有先例，且是社区公认的「反复出现」现象**（强证据，见 C2）。
2. **没有任何成体系的「emoji↔机制术语」对照表**。中文与英文社区搜到的「原神 emoji」内容全部是官方表情包/贴纸（hoyolab 97 种表情说明、B 站表情码、npm 包 mihoyoemoji），与爆料隐写无关。**未找到译稿可抄**。
3. 7.4 四张图不是孤立单发，属于「7.4 璃月整体加强」批次的一支；同批还有**钟离、刻晴、烟绯、重云、凝光**（C1）。
4. 文体性质判断：**爆料者自造黑话 + 规避自动检测**，不是官方内部文档隐写（第五节）。

### C2 「全表情符号爆料」是固定习惯（强证据，社区原话）

- 链接：https://ngabbs.com/read.php?tid=47107615&rand=619
- 标题：7.x钟离雷神加强要来了；帖内时间 **2026-07-04 18:04 修改 / 18:12 发言**。
- 原文抄录（三句，同一楼层）：
  - 「现在动不动全表情符号爆料的习惯能不能改一改」
  - 「主楼爆料IP跟之前说冰雷风一起打的相同，怕不是同一个人」
  - 「反正就凭星超导星扩散状态不能共存就能判定之前那一串表情符号是纯编料」
- 证据类型：**社区讨论**（对原始爆料的评价）。
- 三条可抽取事实：
  1. 2026 年 7 月时，该文体已被称作「习惯」，即非一次性事件；
  2. **同一爆料者用同一文体发过多批**（「之前说冰雷风一起打的」），指向个人风格；
  3. 社区曾用机制互斥（星超导与星扩散状态不能共存）判定某串符号为「纯编料」——文体本身不携带可核验的精确信息。

### C3 Telegram 搬运号沿用了 emoji 版式（7.4 同期）

- 链接：https://tgstat.ru/en/channel/@vanileaks/17381
- 频道：`@vanileaks`（Ванильные Сливки | Genshin Impact），帖号 17381，标题「❖ Обновление 7.4 ❖」。
- 原文抄录：「• 🟩 • Два новых персонажа — 5★ 💦Гидро копейщица [😊Мадам Пин] и 4★ ❄️Крио 🌠каталистка [Цин Пин]. • 🟩 • Баффы персонажей Ли Юэ. • 🟩 • Скины на 🍆Сяо и 🍉Янь Фэй.」
- 可抄出的符号用法（**俄语搬运号的译法，非中文原图译法**）：
  - `🟩` = 项目符号（列表点）
  - `💦` = 水元素（Гидро）
  - `❄️` = 冰元素（Крио）
  - `🌠` = 法器（каталист，武器类型）
  - `😊` = 贴在「萍姥姥」名前，作角色标识
  - `🍆` = 魈（Сяо）
  - `🍉` = 烟绯（Янь Фэй）
- 证据类型：**搬运**（俄语社区转述 7.4 爆料，含璃月角色加强）。
- 限制：tgstat 页面被 Cloudflare 拦截（HTTP 403 `Just a moment...`），**精确发布时间未取得**；仅凭帖序（17381）与「Обновление 7.4」标题判定为 7.4 前瞻期。
- 注意：这里的 emoji 是**前置标记**（🍆魈），不是替代词本身；与中文原帖「emoji 替代词」的用法不同——说明这套写法**没有统一编码约定**。

## 四、文体「意图层级」判断

**判断：爆料者自造黑话，兼带规避关键词/图像自动检测；不是官方内部文档的隐写。** 依据五条：

1. **同一人多批次复用**：C2 原话「主楼爆料IP跟之前说冰雷风一起打的相同，怕不是同一个人」——个人风格特征，机构文档不会有「风格」。
2. **语法不统一**：C3 俄语搬运号把 emoji 当**前置标记**（🍆魈），中文原帖把 emoji 当**词的替代**；两套用法并存且无人校正，说明不存在约定的编码表。
3. **社区能一句话证伪**：C2「凭星超导星扩散状态不能共存就能判定…纯编料」——符号串承载的不是精确机制描述，否则不会犯这种自相矛盾。
4. **第三方描述为「刻意含糊」**：lifemoment520（2026-07-16 文章「新超导居然分为两个队伍」）原话「有些所谓的舅舅在爆料的时候就喜欢藏着掖着说，甚至用一些 emoji 表情来替代，所以大家也只能发散思维推测一下」。链接 https://lifemoment520.com/author/moyifei12345/page/12/?amp （该文不在第 12 页，正文由索引片段取得，未逐字复核整页）。
5. **反证方向**：C1/C3 的**名单层**能与有历史命中率的账号对上，所以名单可能为真、承载数值与命座细节的符号层可信度显著更低。

结论用法：这套符号应视为**语义不封闭的黑话**，不能反推官方术语；解码图面时每一处符号都必须靠外部机制共识（如命座固定结构 C1/C2/C4/C6）交叉验证。
